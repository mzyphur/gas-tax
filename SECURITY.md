# Security policy

This repository hosts a static public-interest policy document, public
chart source, rendered chart assets, and release files. There are no
servers, no user data, no authentication, and no commercial dependencies.

## Reporting a security issue

If you find a security concern with a published file, dependency listing,
or public chart script in this repository, please email
**support@instats.org** rather than opening a public issue. You can
expect an acknowledgement within 7 days.

## What is NOT a security issue

- **A factual error in the report text or a chart number.** Please use
  a public issue instead.
- **A policy disagreement with the report's analysis.** That's a
  different kind of conversation; if grounded in a primary source the
  report missed, a public issue is the right venue.
- **A build failure on your local machine due to missing dependencies.**
  Please use a public issue; that's a setup question, not a security
  concern.

## Supported versions

Only the **latest** release is supported. Previous versions remain
tagged and downloadable for archival purposes (citations may pin a
specific version), but no security fixes are backported.
